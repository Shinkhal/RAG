# Cloudflare R2 Storage

**File:** `app/clients/r2.py`

## Responsibilities
- Store PDF documents
- Generate S3-compatible signed URLs
- No egress fees (critical for cost)

## Key Methods
```
upload_document(user_id: str, document_id: str, file_data: bytes) -> str
get_document_url(user_id: str, document_id: str, expires_in: int) -> str
delete_document(user_id: str, document_id: str) -> None
```

## Path Structure
```
documents/{user_id}/{document_id}.pdf
chunks/{user_id}/{document_id}/chunk_{idx}.json
```

## Notes
- Cost: ~$5/mo
- S3-compatible API (boto3 works)
- Zero egress fees vs. S3 ($0.09/GB)
